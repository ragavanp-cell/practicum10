# TrainSphere — Corporate Training and Workshops

Single-page **TrainSphere** (Corporate Training and Workshops) enquiry form and live notification timer portal (`setInterval`, `clearInterval`, `setTimeout`, `clearTimeout`, and `querySelector` validation), ready for GitHub and Vercel.

## Files Included
- `index.html` — Root entry point for GitHub Pages and Vercel
- `trainsphere-workshops-enquiry.css` — External stylesheet for layout, form inputs, and responsive breakpoint
- `trainsphere-workshops-enquiry.js` — Form validation and notification timer script
- `vercel.json` — Vercel static hosting configuration
